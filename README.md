# Дневник тренировок — PWA для iPhone

Записи тренировок с секундомером, вес и объёмы тела, графики прогресса.
Работает без интернета, данные хранятся только на телефоне.

## Как установить

Приложению нужен адрес с https. Самые простые бесплатные способы:

**GitHub Pages**
1. Создайте публичный репозиторий и загрузите в него содержимое этой папки (index.html, sw.js, manifest.webmanifest, icons/).
2. Settings → Pages → Source: Deploy from a branch → main / root → Save.
3. Через минуту сайт будет доступен по адресу вида https://ИМЯ.github.io/РЕПОЗИТОРИЙ/

**Netlify**
1. Зайдите на app.netlify.com/drop (нужен бесплатный аккаунт).
2. Перетащите туда папку `trainlog` целиком.

Потом на iPhone:
1. Откройте адрес сайта в **Safari**.
2. Нажмите «Поделиться» → «На экран „Домой“».
3. Запускайте дневник с иконки — он откроется во весь экран.

## Данные

- Хранятся в памяти Safari для этого приложения, никуда не отправляются.
- Раздел «Ещё» → «Сохранить резервную копию» сохраняет файл в «Файлы» или iCloud Drive.
- Если удалить иконку с экрана «Домой», iOS удалит и данные приложения — сначала сохраните копию.

## Обновление

Если меняете файлы, увеличьте номер версии в sw.js (`trainlog-v1` → `trainlog-v2`),
чтобы телефон подхватил новую версию. Новая версия появится при втором запуске.
